# WorkdayTracker status

The live status and history of WorkdayTracker: [status.workdaytracker.com](https://status.workdaytracker.com).

Checked every five minutes by [Upptime](https://upptime.js.org) from GitHub Actions. The
history is this repo's commits; each incident is an issue.

The Upptime workflows are pinned to the version in `.github/workflows`. The template's
self-update workflow is left out, because the repo's Actions token may not rewrite workflows.
To update, copy the newer files from upptime/upptime.
